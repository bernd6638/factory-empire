# Factory Empire – Updates

Dieses Repository verteilt die automatischen Updates für **Factory Empire**.

- `update.json` – aktuelle Version, Neuigkeiten und Prüfsumme (wird vom Spiel beim Start abgefragt)
- `updates/` – Spielpakete (nur Spielcode und Grafiken) für die Installation im Spiel

Das Spiel lädt Updates selbst herunter – hier muss niemand etwas manuell herunterladen.
